# Isle

Программа для Windows с компонентами. Сейчас в ней один компонент — **музыкальный островок**:
плавающая панель с обложкой, названием, управлением и живой волной от реального звука.
Интерфейс главного окна сделан в стиле Discord.

Пользователю Python не нужен — он ставит обычный `Isle-Setup-x.y.z.exe`.

## Как работает
- **Музыка**: Windows Media Session (SMTC) — Spotify, Яндекс Музыка, браузеры, плееры.
- **Волна**: WASAPI loopback (то, что реально играет в колонках) → FFT → 32 полосы.
  Если захват недоступен, волна рисуется синтетически, пока играет музыка.
- **Островок**: наведи — раскроется; тащи мышью; ПКМ — меню; клик по полоске — перемотка.
- **Трей**: закрытие окна сворачивает в трей; автозапуск включается в «Основные».

## Сборка установщика
**Вариант 1 — локально (Windows):** поставь Python 3.12 и [Inno Setup 6](https://jrsoftware.org/isdl.php), запусти `build.bat`.
Результат: `dist\Isle-Setup-<версия>.exe`.

**Вариант 2 — GitHub Actions:** положи проект в репозиторий и создай тег:
```
git tag v1.0.0 && git push origin v1.0.0
```
Workflow соберёт установщик и прикрепит его к Release.

## Автообновление
1. В `app/constants.py` замени `GITHUB_REPO = "OWNER/isle"` на свой `owner/repo`.
2. Выпускай релизы с тегами `v1.1.0`, `v1.2.0`… и файлом `Isle-Setup-*.exe` в ассетах.
3. Приложение проверяет `releases/latest`, скачивает установщик (проверяя SHA-256, если GitHub его отдаёт)
   и запускает его с `/SILENT`. Установка идёт в профиль пользователя, поэтому UAC не нужен.

## Добавление новых компонентов
Каждый компонент = страница в `app/main_window.py` + пункт в `_side_list` (+ свои ключи в `app/config.py`).
Рейл слева и кнопка «+» уже подготовлены.

## Разработка и предпросмотр
```
pip install -r requirements.txt
python main.py --demo      # демо-плеер без Windows
python main.py             # настоящий режим
```
Лог: `%APPDATA%\Isle\isle.log`, настройки: `%APPDATA%\Isle\config.json`.
